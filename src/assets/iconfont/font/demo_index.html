Unicode quotes

Unicode It is the most original application method of fonts on the web page, and its features are:

  • Supports dynamically adjusting icon size, color, etc. according to fonts.
  • Multicolor is not supported by default. Adding multicolor icons will automatically decolorize.

Note: The new version of iconfont supports two ways to reference multi-color icons: SVG symbol reference method and color font icon mode. (Using colored font icons requires the Color option to be turned on in "Edit Project" and regenerated.)

The steps to use Unicode are as follows:

Step 1: Copy the generated project@font-face

@font-face {
  font-family: 'iconfont';
  src: url('iconfont.woff2?t=1676543753345') format('woff2'),
       url('iconfont.woff?t=1676543753345') format('woff'),
       url('iconfont.ttf?t=1676543753345') format('truetype');
}

Step 2: Define the style that uses iconfont

.iconfont {
  font-family: "iconfont" !important;
  font-size: 16px;
  font-style: normal;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}

Step 3: Select the corresponding icon and get the font encoding, and apply it to the page

<span class="iconfont">&#x33;</span>

"iconfont" is the font-family under your project. You can view it by editing the project, the default is "iconfont".

font-class reference

font-class is a variant of the way Unicode is used, mainly to solve the problem of unintuitive writing and unclear semantics.

Compared with Unicode usage, it has the following characteristics:

  • Compared with Unicode, the meaning is clear and the writing is more intuitive. It is easy to tell what this icon is.
  • Because class is used to define icons, when replacing icons, you only need to modify the Unicode reference in class.

The steps for use are as follows:

Step 1: Introduce the fontclass code generated below the project:

<link rel="stylesheet" href="./iconfont.css">

Step 2: Select the corresponding icon and get the class name, and apply it to the page:

<span class="iconfont icon-xxx"></span>

" iconfont" is the font-family under your project. You can view it by editing the project, and the default is "iconfont".

Symbol Quote

This is a brand new way of use. It should be said that this is the mainstream in the future and is also the current recommended usage by the platform. For related introductions, please refer to this article article This usage is actually to create a collection of SVGs, which has the following characteristics compared to the other two:

  • Multi-color icons are supported and are no longer restricted by monochrome.
  • With some tips, we support the adjustment of styles through font-size, color like font.
  • Poor compatibility, supports IE9+, and modern browsers.
  • The performance of browser rendering SVG is average, not as good as png.

The steps for use are as follows:

Step 1: Introduce the symbol code generated below the project:

<script src="./iconfont.js"></script>

Step 2: Add general CSS code (introduce it once):

<style>
.icon {
  width: 1em;
  height: 1em;
  vertical-align: -0.15em;
  fill: currentColor;
  overflow: hidden;
}
</style>

Step 3: Select the corresponding icon and get the class name, and apply it to the page:

<svg class="icon" aria-hidden="true">
  <use xlink:href="#icon-xxx"></use>
</svg>
